# B300 Price Check

A Codex Skill for researching current NVIDIA B300 GPU rental and purchase offers.

## What it does

- Finds current B300 rental and purchase offers
- Compares verified prices
- Checks availability and locations
- Notes important extra costs and contract conditions
- Separates different offer types so prices are compared fairly
- Checks provider credibility using observable evidence
- Avoids presenting unverified or outdated prices as current

## Main file

`SKILL.md` contains the instructions used by the AI.

## Purpose

This project makes B300 market research more consistent, verifiable, and reusable.
